# Poise (Rust) starter

1. In the panel, open **Environment** and add `DISCORD_TOKEN`.
2. Press **Start**. The first start compiles the bot in a build container (several minutes and
   about 3 GiB of RAM while it builds; the running bot needs far less).
3. Invite the bot with the `bot` and `applications.commands` scopes and run `/ping`.
